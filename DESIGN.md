# Обновлённый дизайн Малого совета

Откройте preview.html в браузере: это самостоятельная демонстрация заседания без входа и подключения к API. Данные вымышлены, действия не сохраняются.

app.html — рабочий интерфейс, board.html — табло, static/council.css — единые стили. Сервер main.py отдаёт HTML из корня проекта.

Использованы Unbounded, бирюзовый #21b1a6 из референсов, тёмный #102f32 и светлые мятные поверхности. Шрифт загружается через Google Fonts и требует доступа к интернету; резервный — sans-serif.

Адаптация: боковая навигация на широком экране, горизонтальная на телефоне; карточки перестраиваются в одну колонку.

Проверено: синтаксис JavaScript всех трёх страниц. Визуальная проверка не завершена: среда запретила подключение к локальному серверу. Проверка полного API не проводилась; в текущем Python-окружении отсутствует qrcode.
